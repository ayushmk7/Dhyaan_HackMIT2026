## Method / caveats (read first)
- Reddit is fully blocked in this environment (fetch tool refuses reddit.com, direct request returns a block page, and site:reddit.com web searches return no reddit URLs). So there are ZERO first-hand subreddit signals below. Substitutes: GitHub issues (API, exact reaction/comment counts), HN Algolia (exact points/comments), trade forums (allnurses, TruckersReport, Mike Holt, AgTalk, EMTLife, PPRuNe, Cloudy Nights, ChefTalk, Elite Trader, ALZConnected, Alzheimer's Society), App Store reviews, Cursor forum (Discourse JSON), vendor communities (QuickBooks, AccountingWEB).
- "Evidence" column: STRONG = I fetched the page and saw counts/quotes; MEDIUM = URL and snippet seen in search results but page fetch blocked (403); WEAK = low engagement or secondhand.
- Format per signal: URL | who | quote/paraphrase | spread | sponsor tech.
