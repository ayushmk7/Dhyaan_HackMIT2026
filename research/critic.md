# Critic pass — HackMIT 2026 (written 2026-09-19, ~25 min, ~50 searches)

Method: one Devpost `site:` search + one product/web search per idea; deeper checks on the strong ones (products, dataset shape, telephony gating). "no near-duplicate found" means my searches found nothing close, not that nothing exists. Links are only ones a search actually returned.

Cross-cutting feasibility facts that changed verdicts:
- ElevenAgents phone numbers require Twilio (or SIP trunk); no native number purchase. Budget ~1–2h for Twilio signup + A2P/verification; keep the ElevenLabs web-widget call as the fallback demo. https://elevenlabs.io/docs/eleven-agents/phone-numbers/twilio-integration/native-integration
- Ramp "approvals add-step" endpoint: could not verify in search (support docs only describe workflow builder). Treat human-review as your own queue UI; Ramp demo MCP for data is the safe load-bearing piece.
- PUDL: plant-level generation is MONTHLY (EIA-923); HOURLY is only per balancing authority by fuel (EIA-930). Any "solar plant on an overcast day" pitch must be restated at BA-hour or plant-month granularity. https://docs.catalyst.coop/pudl/en/latest/data_sources/eia930.html
- NOAA ISD is a historical archive, not a forecast. Any "will I see it tonight" feature needs a forecast source (NOAA/Open-Meteo); ISD is then decoration for Voloridge.
- Grok Imagine video is async, ~$1.20 per 15 s, minutes per clip: pre-generate everything before the demo.
- Muse connectors need public HTTPS + US Muse account, no dev docs: do not make any demo depend on it.
- Coding-agent token profilers are a crowded open-source category (Token Meter, TokenScope, tokenamun, agentprof, ccusage): a profiler alone is not a hack.
